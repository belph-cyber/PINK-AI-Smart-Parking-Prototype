# คู่มือใช้งาน PINK AI Smart Parking

## 1. การเข้าใช้งาน

1. เปิด URL ที่ผู้ดูแลระบบแจ้ง
2. เข้าระบบด้วยบัญชีที่ได้รับอนุญาต
3. ระบบแสดงเมนูตามบทบาทของบัญชี
4. ออกจากระบบเมื่อเลิกใช้งาน โดยเฉพาะเครื่องสาธารณะ

การดูตัวอย่างบทบาท (ถ้ามี) เป็นเพียง preview และไม่ใช่การยืนยันว่า API/ฐานข้อมูล/ฮาร์ดแวร์เชื่อมต่ออยู่

## 2. นักศึกษาและอาจารย์

- ดูทะเบียน สถานะตำแหน่งล่าสุด และประวัติเข้าออกของตนเอง
- เพิ่มทะเบียนรถของตนเองได้ตามนโยบายระบบ; ทะเบียนซ้ำกับบัญชีอื่นต้องไม่ถูกผูกซ้ำ
- ตรวจป้ายสถานะว่าอุปกรณ์รายงานเมื่อใดและข้อมูลสดหรือเก่า
- สถานะ “ทราบชั้น แต่ยังไม่ทราบช่อง” หมายถึงกล้องระบุชั้นได้ แต่หลักฐานยังไม่พอจะระบุช่องจอด
- ใช้แชทติดต่อ รปภ. เพื่อสอบถามหรือแจ้งข้อมูลผิดปกติ
- หากระบบแจ้งทะเบียนหรือประวัติไม่ถูกต้อง ให้ติดต่อ รปภ. ห้ามใช้ตำแหน่งที่แสดงเป็นหลักฐานยืนยันเมื่อมีป้าย stale/offline/unknown

ผู้ใช้ไม่เห็นทะเบียน ประวัติ หรือรายละเอียดบุคคลอื่น

## 3. รปภ.

- ตรวจคิวเหตุการณ์ที่ต้องทบทวน พร้อมเวลาตรวจ กล้อง ค่า confidence และภาพหลักฐานตามสิทธิ์
- หากแก้ผลอ่าน ให้บันทึกผลต้นฉบับและค่าที่แก้แยกกัน พร้อมเหตุผลและผู้ดำเนินการ
- คำสั่งเปิด/ปิดประตูต้องทำผ่านหน้าควบคุมที่ได้รับอนุญาตและใส่เหตุผลตามข้อกำหนด
- ตรวจคำตอบกลับของ controller และ physical feedback แยกจากข้อความว่า “ส่งคำสั่งแล้ว”
- ติดต่อผู้ใช้ผ่านแชท ไม่ส่งข้อมูลผู้ใช้อื่นให้ผู้ใช้ที่ไม่เกี่ยวข้อง

## 4. แอดมิน

- เพิ่ม/แก้ไข/ปิดใช้งานบัญชีตามสิทธิ์
- ตรวจ audit log เพื่อดูผู้แก้และเวลา
- ตั้งค่า/ตรวจสถานะอุปกรณ์เฉพาะเมื่อได้รับสิทธิ์
- ห้ามใช้เครื่องมือ bootstrap/reset ที่ลบฐานข้อมูลกับข้อมูลจริง

## 5. การอ่านสถานะช่อง

| ป้าย | วิธีตีความ |
|---|---|
| ว่างยืนยัน | sensor รายงานสดและผ่านเกณฑ์ว่าว่าง |
| มีรถ | sensor รายงานว่ามีรถ/วัตถุ |
| สงวน/กำหนดสิทธิ์ | ช่องมีการจัดสรร/สิทธิ์ที่บันทึกไว้ตามนโยบาย |
| ไม่ทราบ | ไม่มีหลักฐานพอ ข้อมูลหมดอายุ หรือยังจับคู่รถกับช่องไม่ได้ |
| ขัดข้อง | อุปกรณ์แจ้งข้อผิดพลาด |
| ขัดแย้ง | หลักฐานหลายแหล่งให้ผลต่างกัน |

ช่อง “ไม่ทราบ”, “ขัดข้อง” และ “ขัดแย้ง” ไม่ได้หมายความว่าว่าง

## 6. ปัญหาการเชื่อมต่อ

- หากป้ายบอก offline/stale ให้ใช้ข้อมูลเป็นสถานะล่าสุดที่ทราบ ไม่ใช่สถานะปัจจุบัน
- แจ้ง รปภ. เมื่อการตรวจรถ/ข้อมูลตนเองไม่ตรง
- ห้ามทดลองสั่งไม้กั้นจริงนอกขั้นตอนที่ผู้รับผิดชอบอนุญาต
