# หน้าที่และความรับผิดชอบสมาชิก

## มิน — Project Manager / Business Analyst / UX/UI และผู้ประสานงานสำรวจพื้นที่
คิดหัวข้อ รวบรวมและจัดการข้อมูล แบ่งงานและติดตามความคืบหน้า จัดทำเอกสาร สไลด์และวิดีโอ รวบรวม Requirements ส่งให้ผู้พัฒนา ออกแบบแนวทางหน้าเว็บ วางตำแหน่งกล้อง/เซนเซอร์ และเชื่อมกล้องเข้ากับเครือข่ายเพื่อหา IP สำหรับตั้งค่า CiRA

## โอ — Full-Stack Developer / CiRA Integration Engineer / ผู้ออกแบบวงจรเซนเซอร์
รับ Requirements และแนวทางดีไซน์จากมิน พัฒนาเว็บ รายงานปัญหาที่พบ เตรียมระบบ CiRA เชื่อม API CiRA กับเว็บ และออกแบบวงจรเซนเซอร์เพื่อส่งต่อให้ริประกอบ

## คริส — AI/ML Engineer (Computer Vision)
รับชุดภาพจากมิน จัดเตรียมข้อมูล ฝึกหรือปรับ AI เพื่อเพิ่มความแม่นยำ ทดสอบผล และสรุปตัวชี้วัดกับกรณีที่ AI ยังตรวจผิด

## ริ — IoT/Embedded Systems Engineer / ผู้ติดตั้งภาคสนาม
ประกอบวงจรเซนเซอร์ตามแบบของโอ ติดตั้งในพื้นที่จริง และทดสอบการวัด/ส่งสถานะ พร้อมบันทึกปัญหาที่พบ

## การทำงานร่วมกัน
มินประสานและสรุป Requirements; โอรับผิดชอบการพัฒนาและการเชื่อม CiRA; คริสดูแลผล AI; ริทำวงจรและติดตั้งเซนเซอร์ ทุกคนร่วมทดสอบระบบและแนบหลักฐานงานที่ตนทำจริงก่อนส่งรายงาน
