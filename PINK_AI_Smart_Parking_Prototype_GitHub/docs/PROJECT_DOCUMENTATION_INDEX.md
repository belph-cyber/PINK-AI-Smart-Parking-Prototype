## สถานะเอกสาร

เอกสารชุดนี้จัดทำเพื่ออธิบายโครงงานให้สอดคล้องกับวิชา **ระบบการรับภาพด้วยเครื่อง** และข้อกำหนดระบบจอดรถที่ตกลงกับผู้ใช้ เอกสารแยกข้อกำหนดที่ยืนยันแล้วออกจากรายละเอียดที่ต้องตรวจสอบกับอุปกรณ์และผู้ดูแลพื้นที่จริง

## สถานะความพร้อม

เอกสารและซอร์สเว็บ/API พร้อมใช้เป็นฐานสำหรับพัฒนาและสาธิตแบบแยกส่วน การเชื่อม CiRA, กล้องจริง, MQTT broker, ESP32, อุปกรณ์ตอบกลับไม้กั้น/ตรวจการผ่าน และฐานข้อมูลเป้าหมายต้องตรวจสอบในสถานที่จริงก่อนกล่าวว่าใช้งานจริงแล้ว

## ประเด็นที่ต้องยืนยันก่อนรับรองระบบ

1. ป้ายจอดเฉพาะเป็นสิทธิ์จอดประจำหรือการจองตามช่วงเวลา
2. กล้อง CiRA ส่งภาพและผล LPR ผ่านโปรโตคอล/รูปแบบ payload ใด และตั้งค่าความละเอียด/FPS เท่าใด
3. ขาออกจากอาคารและหลักฐานยืนยันการผ่านใช้กล้อง เซนเซอร์ หรืออุปกรณ์ใด
4. ขอบเขตการควบคุมไม้กั้นจริงและผู้มีสิทธิ์อนุมัติกรณียกเว้น
5. ความสดของข้อมูล (timeout), เกณฑ์ความมั่นใจ, หน้าต่างเวลาจับคู่ และระยะเก็บภาพ/ประวัติตามนโยบายมหาวิทยาลัย
