จัดการผู้ใช้ครบ 4 Roles, จัดการช่องจอด, เชื่อมต่อ Google Sheets (Apps Script), และตรวจสอบประวัติ Login/Audit

Database (SQLite) เป็น Source of Truth หลัก • ป้องกันข้อมูลซ้ำด้วย Unique Key • ไม่ส่งออก Password / Hash เด็ดขาด

โค้ดสำหรับ Google Apps Script (google_apps_script/Code.gs)

1. เปิดไฟล์ Google Sheets ของคุณ -> คลิกเมนู ส่วนขยาย (Extensions) > Apps Script
2. กดปุ่ม คัดลอกโค้ดทั้งหมด ด้านล่างไปวางแทนที่ แล้วกด Deploy > New deployment > Web app (Execute as: Me, Who has access: Anyone)
3. นำลิงก์ Web App URL (ลงท้ายด้วย /exec) กลับมาวางในช่องตั้งค่าแล้วกดซิงก์ได้ทันที!
